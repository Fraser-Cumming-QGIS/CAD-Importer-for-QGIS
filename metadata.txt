about=CAD Importer provides a repeatable Processing workflow for bringing CAD drawings into QGIS. It imports DXF files directly and converts DWG files using a separately installed ODA File Converter. Download ODA File Converter from https://www.opendesign.com/guestfiles/oda_file_converter. Imported features are assigned the selected CRS, repaired, cleaned of duplicate geometry and empty fields, separated by CAD layer and geometry type, labelled from CAD text where available, and styled for inspection. ODA File Converter is not included and DWG conversion is currently supported on Windows. Unlike general-purpose CAD importers, CAD Importer focuses on automated cleanup and ready-to-use QGIS layers after import.
